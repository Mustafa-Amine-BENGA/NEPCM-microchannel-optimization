# Data

- `results.csv`: the 100 design points of the optiSLang study (inputs and Fluent outputs)
- `design_results.csv`: optiSLang design table
- `fluent_optimum_validation.csv`: Fluent computation of the optimum
- `optislang/`: PEC and T_max response surfaces exported from the optiSLang metamodel (φ = 0, s_x = 1.5)
- `fluent_exports/`: Fluent ASCII exports (cell centres) for the field figures, and wall profiles of design DP83
